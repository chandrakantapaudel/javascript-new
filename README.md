# JavaScript Practice Project

This project is a simple JavaScript workspace for running small scripts in the terminal.

## Files

- `.devcontainer/test.js` - sample JavaScript file
- `app.js` - main script for the project

## Run the app

```bash
cd /workspaces/javascript-new
node app.js
```

## Run the sample file

```bash
cd /workspaces/javascript-new
node .devcontainer/test.js
```

## Dev environment

This workspace includes a dev container configuration for JavaScript development.

If you are using VS Code with Dev Containers, reopen the folder in the container and run the commands above.
